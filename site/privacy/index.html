Site analytics

ip-search-mcp counts page views with Umami, open-source analytics software that this site runs itself, hosted on Railway. The tracker script loads directly from umami-production-abb4.up.railway.app, and the data is stored in a database this site controls, not sent to an analytics vendor. It is not used for advertising and is not sold.

Each page view records the page address (including any query string), the referrer, the page title, your browser and operating system, device type, screen size, language, and an approximate location (country, region and city) looked up from your IP address.

  • Umami's documentation says your IP address is used for that lookup and is never stored by Umami; the hosting provider may still log it in routine request logs.
  • The tracker sets no cookies and writes nothing to your browser storage, and Umami's documentation says visitors are not tracked across websites.
  • Repeat visits are counted using a hash of values such as your IP address and browser user agent combined with a salt that rotates monthly by default, rather than a cookie or identifier stored on your device.
  • If your browser sends a Do Not Track signal, the tracker sends no page-view data, though your browser still requests the script.
  • Only pages on bytesbybrandon.github.io are counted, so previews and local copies are not. This site does not use a session recorder.
  • Self-hosted Umami keeps data until it is deleted and has no automatic expiry.
